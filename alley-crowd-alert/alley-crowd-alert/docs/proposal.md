# 공식 혼잡도가 못 보는 골목 아이디어 소개서

2026-10-29 · 서준성

> 2026 글로컬 미래도시 혁신 프로그램(서울시립대학교 창업지원단·캠퍼스타운사업단) 제출용 아이디어 소개서

## 1. 아이템 개요

- 장소 단위 공식 혼잡도가 포착하지 못하는 골목·출구 단위 인파 위험을 AI로 추정·경보하는 서비스
- 청량리역 일대 실증 후 서울 개발 역세권 및 해외 대도시로 확장

| 구분 | 내용 |
| --- | --- |
| 아이템명 | 공식 혼잡도가 못 보는 골목 |
| 한 줄 소개 | 공식 혼잡도가 '보통'일 때도 위험해지는 골목을 찾아내는 AI 인파 조기경보 서비스 |
| 해결 과제 | 장소 단위 공식 혼잡도로는 장소 내부 골목·출구별 위험 구분 불가 |
| 핵심 기술 | 골목 단위 보완 위험지표, 센서 미설치 구간 결측 추정 및 신뢰도 산출 |
| 실증 대상지 | 청량리역 일대(환승 통로, 전통시장, 신축 단지 보행로, 재개발 공사 구간) |
| 목표 고객 | 구청·경찰(B2G), 축제·행사 주최 측, 역사·대형시설·건설사(B2B) |
| 확장 방향 | 청량리 → 서울 개발 역세권 → 해외 대도시 |

## 2. 문제 인식 및 필요성

- 공식 혼잡도는 장소 전체를 4단계로만 표시 → 장소 내부 골목·출구 단위 위험 식별 불가
    - [서울 실시간 도시데이터](https://data.seoul.go.kr/dataVisual/seoul/guide.do): 주요 121곳 대상, KT·SKT 기지국 신호 5분 단위 집계, 붐빔·약간 붐빔·보통·여유 4단계 제공
    - 내부 산출은 50m×50m 격자 기반이나 격자 원자료는 통신사 계약상 비공개 → 구청·행사 운영자는 장소별 단계 1개만 확인 가능
- 현장 관리 공백
    - 해상도 공백: 장소 평균이 '보통'이어도 출구·경사 골목 등 병목 지점은 위험 수준 도달 가능
    - 범위 공백: 121곳은 관광지·교통요지 중심 선정 → 명절 전통시장, 대학 축제 등 일시적 밀집 현장은 제외되기 쉬움
- 제도적 수요 확대
    - 2022년 이태원 참사 이후 재난안전법 개정: 다중운집 사고를 재난 유형에 포함, 지자체장 안전관리 의무 명문화([아시아경제, 2026.4.20](https://view.asiae.co.kr/article/2026042008254119912))
    - 2025.10.2. 개정 시행령 시행: 순간 최대 5천 명 이상 축제, 1일 이용객 5만 명 이상 철도역사 등 매년 실태조사, 긴급 시 행사 중단·해산 권고 가능([보안뉴스, 2025.9.16](https://www.boannews.com/news/articleView.html?idxno=139285))
    - 1천 명 미만 소규모 행사는 여전히 관리 사각지대

## 3. 해결 방안

- 공식 지표 진단 → 골목 단위 보완 지표 산출 → 관측 공백 결측 추정 → 경보 및 리포트의 4단계 구조

1. 공식 지표 진단
    - 실시간 도시데이터 API 직접 수집·적재(과거 데이터 미제공), 집계구 단위 생활인구·역별 승하차와 중첩 분석
    - 121곳 중 환승역·전통시장 유형 장소에서 장소 단계와 내부 구역 간 편차(변별력 손실) 정량화 후 청량리에 동일 방법 적용
2. 골목 단위 보완 지표
    - 50m 격자·골목 구간별 밀도, 밀도 증가 속도, 출구 병목 유입·유출 불균형 산출
    - 도로 폭·경사 등 공간정보 반영, 구간별 위험 기준 차등 적용
3. 관측 공백 결측 추정
    - 센서·CCTV 미설치 구간을 결측으로 처리, 도로망 인접 구간·승하차 흐름 기반 추정
    - 추정값별 신뢰도 산출, 신뢰도 낮은 고위험 구간은 현장 요원 우선 확인
4. 경보 및 리포트
    - 위험 구간 및 권장 조치(진입 통제, 우회 안내)를 상황실·현장 요원 단말로 전송
    - 행사·공사 종료 후 지자체 실태조사용 사후 리포트 자동 생성

- 활용 데이터: 공개 데이터(사고·통제 정보 포함), 현장 계수 데이터(와이파이 접속 수, 출입구 인원 계수기)
- 개인 식별 정보 미수집, 영상 미저장(집계 수치만 활용)

## 4. 지역특화 및 도시문제 연계성

- 실증 대상지: 청량리역 일대(개발로 유동 인구 구조가 가장 빠르게 변하는 지역)
- 개발 현황
    - 롯데캐슬 SKY-L65, 한양수자인 그라시엘, 해링턴 플레이스 등 초고층 단지 입주 완료, 청량리 6·7·8구역·제기동 일대 재개발 진행([파이낸셜뉴스, 2026.4.9](https://www.fnnews.com/news/202604081001223357))
    - 현재 6개 노선 환승 거점, GTX-B·C 및 버스지하환승센터 추가 계획
    - 2030년 12개 철도 노선, 하루 유동인구 30만 명 규모의 동북권 최대 교통 거점 전망(동대문구, [파이낸셜뉴스, 2026.1.8](https://www.fnnews.com/news/202601081815158245))
- 지역 현안: 개발 단계마다 병목 위치 변동 → 고정된 관리 기준으로 대응 곤란
    - 신규 단지 입주, 공사에 따른 보도 축소·출구 변경 시 병목 이동
    - 동대문구도 청량리역 중심 보행축 정비, 전통시장 권역 동선·안전 개선 추진 중 → 보행 안전 데이터 수요 존재

| 관리 지점 | 밀집 시기 | 변동 위험 요인 |
| --- | --- | --- |
| 청량리역 환승 통로·출구 | 출퇴근, 행사 귀가 | 신규 노선·환승센터 공사에 따른 동선 변경 |
| 청량리역 광장(청량리세종광장 조성 예정) | 행사, 환승 대기 | 시설물 이전·공간 재배치 |
| 경동시장·청량리 전통시장 골목(10여 개 시장 밀집) | 명절 대목, 주말 | 좁은 골목, 신규 상업시설 유입 |
| 초고층 단지~역 연결 보행로 | 출퇴근 | 단지 입주 시 보행량 급증 |
| 재개발 공사 구간 | 공사 기간 | 가설 보행로·폐쇄 출구로 병목 이동 |

- 지역 자원 활용
    - 서울시립대: 청량리와 동일 생활권, 교내 축제를 센서 보정 시험장으로 활용, 공간정보 역량으로 공사 구간 보행로 폭·경사 측정
    - 동대문구·지역 대학 창업 협력 체계(DDM Union): 구청 안전 부서와 실증 협의 경로
- 기대 효과: 개발 단계별 보행 안전 점검 및 다중운집 실태조사의 데이터 기반 수행

## 5. 아이디어 혁신성

- 기존 방식은 센서 설치 지점만 관측, 본 서비스는 미관측 구간을 결측 문제로 처리하여 추정값과 신뢰도를 함께 제공

| 방식 | 관측 단위 | 미관측 구간 처리 | 결과물 |
| --- | --- | --- | --- |
| [서울 실시간 도시데이터](https://data.seoul.go.kr/dataVisual/seoul/guide.do) | 주요 121곳, 장소 전체 | 목록 외 지역 미제공 | 장소별 혼잡 4단계 |
| CCTV 영상 분석 | 카메라 화각 내 | 카메라 미설치 골목 공백 | 지점별 밀집 감지 |
| [와이파이 신호 집계(IoT)](https://view.asiae.co.kr/article/2026042008254119912) | 센서 반경 내 | 센서 미설치 구간 공백 | 지점별 인원 추정 |
| 본 서비스 | 50m 격자·골목 구간 | 결측 추정 및 신뢰도 표시 | 위험 구간·권장 조치 경보, 실태조사 리포트 |

- 차별점
    - 공식 지표의 변별력 손실을 사전 진단하여 보완 필요 구간 특정
    - 관측 공백을 결측 추정으로 보완, 불확실 구간은 현장 확인으로 연결
    - 골목 폭·경사를 반영한 구간별 위험 기준 적용
    - 개발로 이동하는 병목을 주기적 재진단으로 추적
- 기존 CCTV·와이파이 센서를 대체하지 않고 입력으로 활용하는 소프트웨어 계층 → 도입 비용 최소화

## 6. 사업화 가능성

- 1차 고객: 법적 안전관리 의무가 생긴 지자체, 안전 책임을 지는 행사·시설·공사 주체

| 고객 | 수요 | 제공 상품 | 과금 방식 |
| --- | --- | --- | --- |
| 구청 재난안전 부서 | 매년 다중운집 실태조사, 축제 모니터링 | 상시 모니터링 + 실태조사 리포트 | 연간 구독 |
| 축제·행사 주최 측 | 안전관리계획 수립, 현장 통제 근거 | 계수기 설치·경보 운영·사후 리포트 | 행사 단위 패키지 |
| 철도역사·대형 점포 운영사 | 출구·통로 병목 관리 | 시설 병목 모니터링 | 시설 단위 구독 |
| 건설사 | 공사 구간 보행 안전 관리 | 가설 보행로 병목 모니터링 | 공사 기간 단위 계약 |

- 수익 구조
    - 진단·지표 산출 코드 GitHub 공개 → 기술 신뢰 확보, 심사위원·잠재 고객 직접 검증 가능
    - 현장 운영(센서 연동, 경보, 리포트)은 유료 서비스로 제공
- 실행 가능성
    - 소프트웨어 중심 구조로 초기 비용 낮음, 공개 데이터만으로 진단 즉시 착수 가능
    - 현장 장비는 영상 미저장 저가 계수기로 충분
    - 공공 영업 장기화 대비: 행사·공사 단위 계약으로 실적 확보 후 구청 구독으로 확대

## 7. 성장 및 글로벌 확장

- 진단·추정 모델은 입력 데이터만 교체하면 타 도시 적용 가능 → 단계적 확장

1. 청량리: 환승역·전통시장·신축 단지·공사 구간에서 검증
2. 서울 개발 역세권: 동일 공식 지표를 쓰는 자치구로 확대, 진단 리포트로 진입
3. 전국 지자체: 실태조사 대상(5천 명 이상 축제, 1일 5만 명 이상 철도역사) 공통 수요 공략
4. 해외 대도시: 역세권 개발이 활발하고 대형 인파 행사가 잦은 아시아 대도시부터 진출

- 해외 적용 근거: 공식 혼잡 정보가 넓은 단위로 제공되고 센서가 일부 지점에만 있는 도시는 동일 문제 발생, 도시별로는 데이터 연결부만 교체
- 진출 경로
    - GitHub 공개 진단 도구로 해외 도시·연구자 유입 → 현장 운영 계약 연계
    - 스마트시티 해외 협력 사업, 해외 공연·행사 기획사와 협력하여 첫 해외 실증지 확보
