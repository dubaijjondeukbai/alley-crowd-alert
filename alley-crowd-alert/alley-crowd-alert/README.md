# 공식 혼잡도가 못 보는 골목

> 공식 혼잡도가 '보통'일 때도 위험해지는 골목을 찾아내는 AI 인파 조기경보, 개발이 한창인 청량리에서 시작해 세계 도시로

서울시립대학교 창업지원단(캠퍼스타운사업단) **2026 글로컬 미래도시 혁신 프로그램** 참가 아이템입니다.

- 아이디어 소개서: [docs/proposal.md](docs/proposal.md)

## 왜 필요한가

서울 실시간 도시데이터는 주요 121곳의 혼잡도를 장소 단위 4단계(붐빔·약간 붐빔·보통·여유)로만 공개합니다. 장소 평균이 '보통'이어도 출구나 좁은 골목 같은 병목은 위험해질 수 있지만, 공식 지표로는 그 차이가 보이지 않습니다.

## 접근 방법

1. **공식 지표 진단**: 실시간 도시데이터를 직접 적재해, 장소 단계가 내부 구역의 차이를 얼마나 놓치는지(변별력 손실) 측정합니다.
2. **골목 단위 보완 지표**: 50m 격자·골목 구간별 밀도, 밀도 증가 속도, 출구 병목의 유입·유출 불균형을 계산합니다.
3. **관측 공백 결측 추정**: 센서·CCTV가 없는 구간을 결측으로 보고 추정하며, 추정값의 신뢰도를 함께 냅니다.
4. **경보와 리포트**: 위험 구간과 권장 조치를 알리고, 지자체 실태조사용 리포트를 만듭니다.

## 데이터 수집 시작하기

실시간 도시데이터 API는 과거 데이터를 주지 않아서, 분석하려면 직접 쌓아야 합니다.

1. [서울 열린데이터광장](https://data.seoul.go.kr)에서 인증키를 발급받습니다.
2. `config/areas.txt`에 수집할 장소명을 넣습니다. [서울 실시간 도시데이터](https://data.seoul.go.kr/dataVisual/seoul/guide.do) 페이지의 '주요 121장소 정보'에 있는 이름만 동작합니다.
3. 실행합니다(Python 3.8 이상, 외부 패키지 없음).

```bash
export SEOUL_API_KEY=발급받은_인증키
python src/collect_citydata.py --areas config/areas.txt --interval 300
```

원본 응답은 `data/raw/날짜.jsonl`에, 요약은 `data/ppltn.csv`에 쌓입니다. `data/` 폴더는 `.gitignore`에 들어 있어 저장소에는 올라가지 않습니다.
